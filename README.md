# Galaxy Book — Telegram-бот бронирования

Бот показывает клиентам расписание помещений из Google Calendar, афишу
мероприятий и принимает заявки на бронь. Администратор подтверждает или
отклоняет заявки прямо в Telegram.

## Что умеет

**Клиент**
- 📅 **Забронировать**: помещение → день → свободное время начала → длительность →
  имя, телефон, кол-во человек, комментарий → заявка.
- 👀 **Занятость на день**: все помещения на выбранный день — что занято, что свободно.
- 🎭 **Афиша**: мероприятия из календаря «Galaxy Book» на 30 дней вперёд.
- 📋 **Мои брони**: список своих броней и их отмена.
- ⏰ Напоминания за 24 ч и за 2 ч до начала.

**Администратор**
- Получает каждую заявку с кнопками «✅ Подтвердить / ❌ Отклонить».
- `/pending` — все заявки, ожидающие решения.
- Получает уведомление, когда клиент отменяет бронь.

## Правила бронирования

| Помещение | Минимум |
|---|---|
| 🏛 Зал | 1 час |
| 🛋 Тапчан (над баром) | 1 час |
| 🎨 Творческая мастерская | 1 час |
| 🎹 Фортепиано | 30 минут |

- Рабочие часы 09:00–22:00, бронировать можно на 30 дней вперёд.
- Время начала выбирается кнопками с шагом 30 минут (9:00, 9:30, 10:00…),
  длительность тоже кратна 30 минутам.
- **Перерыв 5 минут.** Если соседняя бронь стоит вплотную, время сдвигается
  автоматически. Пример: в мастерской заняты 16:00–17:00 и 18:00–19:00, клиент
  выбирает 17:00 на 1 час и получает **17:05–17:55**. Если соседей вплотную нет,
  бронь остаётся 17:00–18:00.
- Пока админ не подтвердил заявку, время уже занято: в календаре появляется
  событие «⏳ Имя (заявка)». После подтверждения название меняется на «Имя»,
  после отказа событие удаляется.
- Клиенты **не видят чужих имён**, только «занято». Мероприятия из календаря
  «Galaxy Book» показываются с названием.
- Мероприятие из «Galaxy Book» занимает помещение, если в поле **«Место»**
  (Location) события написано его название, например «Зал» или
  «Творческая мастерская». Ключевые слова задаются в `config.yaml` → `aliases`.
- События, у которых в Google Calendar стоит «Показывать как: Свободен», не
  считаются занятыми.

Все эти значения меняются в `config.yaml` без правки кода.

## Установка на Windows-сервер

### Шаг 1. Python
Скачайте Python 3.11 или новее с https://www.python.org/downloads/ и при установке
отметьте **«Add python.exe to PATH»**.

Скопируйте папку проекта на сервер, например в `C:\galaxybot`, и запустите
**`install.bat`**. Он создаст окружение, установит библиотеки и файлы
`config.yaml` и `.env`.

### Шаг 2. Сервисный аккаунт Google (один раз)
Сервисный аккаунт — это «робот-пользователь», от имени которого бот работает с
календарями. **Клиентам ничего расшаривать не нужно**: они видят расписание
только через бота.

1. Откройте https://console.cloud.google.com/ и выберите проект **My First Project**.
2. **APIs & Services → Library**: найдите *Google Calendar API* и убедитесь, что он включён (Enable).
3. **IAM & Admin → Service Accounts → Create service account**. Имя, например,
   `galaxy-bot`, остальное можно пропустить.
4. Откройте созданный аккаунт → вкладка **Keys → Add key → Create new key → JSON**.
   Скачается файл: переименуйте его в `service-account.json` и положите в папку бота.
   ⚠️ Никому не пересылайте этот файл: это пароль от календарей.
5. Скопируйте email сервисного аккаунта, вида
   `galaxy-bot@xxxx.iam.gserviceaccount.com`.

### Шаг 3. Открыть доступ к календарям (один раз)
В Google Calendar под galaxybook2018@gmail.com для **каждого** из календарей
Зал, Тапчан (над баром), Творческая мастерская, Фортепиано:

**⋮ → Настройки и общий доступ → Открыть доступ пользователям → Добавить** →
вставьте email сервисного аккаунта → права **«Внесение изменений в мероприятия»**.

Для календаря **Galaxy Book** достаточно прав **«Просмотр всех сведений о мероприятиях»**.

Там же, в разделе **«Интеграция календаря»**, скопируйте **«Идентификатор
календаря»** каждого календаря (вида `...@group.calendar.google.com`) и вставьте
в `config.yaml` в поле `calendar_id`. У основного календаря Galaxy Book
идентификатор — `galaxybook2018@gmail.com`.

### Шаг 4. Telegram-бот
1. В Telegram откройте **@BotFather** → `/newbot`, задайте имя и получите **токен**.
2. Узнайте свой Telegram ID через бота **@userinfobot**.
3. Впишите оба значения в файл `.env`:
   ```
   BOT_TOKEN=123456789:AA...
   ADMIN_ID=123456789
   ```
4. Администратор должен **сам написать боту `/start`**, иначе Telegram не даст
   боту присылать ему заявки.

### Шаг 5. Проверка
Запустите **`check.bat`**. Он покажет email сервисного аккаунта и проверит
доступ к каждому календарю: везде должно быть ✅.

### Шаг 6. Запуск
Запустите **`run.bat`**. Окно должно оставаться открытым. Если бот упадёт или
пропадёт интернет, он перезапустится сам через 10 секунд.

**Автозапуск после перезагрузки сервера:** нажмите Win+R → `shell:startup` →
положите туда ярлык на `run.bat`. Бот будет стартовать при входе в Windows.
Чтобы запускать без входа пользователя, используйте «Планировщик заданий»:
триггер «При запуске компьютера», действие — `run.bat`, флажок
«Выполнять вне зависимости от регистрации пользователя».

## Файлы

| Файл | Назначение |
|---|---|
| `config.yaml` | Настройки: календари, часы, шаг, перерыв, минимумы |
| `.env` | Токен бота и ID админа (секретно) |
| `service-account.json` | Ключ Google (секретно) |
| `bookings.db` | База заявок (создаётся автоматически) |
| `bot.log` | Журнал работы, смотреть при ошибках |

Код:
- `bot/slots.py`: расчёт свободного времени и правило перерыва 5 минут
- `bot/gcal.py`: работа с Google Calendar
- `bot/service.py`: заявки, подтверждение, отмена
- `bot/handlers.py`: диалоги Telegram
- `bot/reminders.py`: напоминания

## Для разработчика
```
pip install -r requirements.txt pytest
python -m pytest
```
Тесты проверяют правила слотов и полный сценарий бронирования с фейковыми
Telegram и Google Calendar.
