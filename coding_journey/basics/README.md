# F-String Examples in Python

This repository contains the file `f_strings_examples.py` with clear examples of how to use **f-strings** in Python.

## What's inside:

1. **Simple variable insertion**  
   How to easily embed values into a string.

2. **Inserting expressions**  
   You can perform calculations directly inside an f-string.

3. **Number formatting**  
   Round numbers to a specific number of decimal places.

4. **Text alignment**  
   Align text to the left, right, or center — useful for tables.

5. **Thousands separators**  
   Format large numbers with commas or spaces.

6. **Embedding quotes inside strings**  
   Insert quotes properly without syntax errors.
